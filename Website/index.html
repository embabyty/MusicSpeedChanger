Clean DSP chain, no dependencies

  • AVAudioUnitTimePitch — independent tempo / pitch
  • 2× chained AVAudioUnitEQ — 31 ISO bands, 20 Hz–20 kHz ±15 dB
  • Apple DynamicsProcessor peak limiter — stops stretch/EQ clipping
  • Same chain for monitoring and WAV / M4A export
